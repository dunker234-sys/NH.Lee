# WORKER_QUICK_GUIDE — 근로자용 1페이지 안내

STEP12 운영 문서. 현장에 인쇄물로 배포하거나 모바일 앱/키오스크 첫 화면에
띄우는 것을 전제로 한다. 전문 용어를 피하고 실제로 근로자가 마주치는 화면
동작 기준으로 작성했다.

---

## 출퇴근 등록(타각), 이렇게 하세요

**세 가지 방법 중 편한 것을 쓰면 됩니다.** 회사 지급 기기가 없어도 됩니다.

1. **모바일 앱** — 큰 버튼 하나로 출근/퇴근. 인터넷이 안 터지는 곳이어도
   버튼을 누르면 일단 저장되고, 나중에 자동으로 전송됩니다(오프라인 큐).
2. **사업장 키오스크(공용 태블릿)** — 화면을 눌러 본인 확인 후 출근/퇴근.
   PIN 번호로 인증합니다(비밀번호와 다른 번호이니 헷갈리지 마세요).
3. **PC 웹** — 사업장 사무실 PC에서 접속해 등록. 등록된 사업장 PC에서만
   됩니다.

## 조기 출근·연장근무는 어떻게 되나요?

**미리 승인받지 않고 일찍 출근하거나 늦게 퇴근해도, 실제로 일한 시간은 전부
기록됩니다.** 사전 승인이 없다고 근무시간이 0으로 지워지지 않습니다. 다만
사후에 관리자가 확인 절차를 거치므로, 사유가 있으면 등록 시 메모를 남겨
주세요(예: 지오펜스 반경을 벗어나 등록한 경우 "왜 그런지" 한 줄 메모가 남을
수 있습니다).

## 쉬는 시간(휴게)은 자동으로 빠지지 않습니다

**시스템이 스케줄만 보고 마음대로 휴게시간을 빼지 않습니다.** 실제로 외출/
복귀를 등록하거나 "휴게를 못 받았다"고 신고한 내용이 우선합니다. 쉬는 시간을
못 받았으면 꼭 신고해 주세요 — 신고가 없으면 반영되지 않을 수 있습니다.

## 내 위치정보, 어떻게 관리되나요?

출퇴근 등록에 쓰인 위치정보는 근태 원본 기록과 **분리해서** 보관되고,
일정 기간이 지나면 자동으로 **파기**됩니다(근태 원본 자체는 3년간 남습니다 —
위치정보만 지워집니다).

- **내 위치정보 열람**: 앱 설정 > 개인정보 > 위치정보 접근 이력에서, 누가
  언제 왜 내 위치정보를 조회했는지 볼 수 있습니다.
- **일시중지**: 앱 설정에서 언제든 위치정보 수집을 일시적으로 멈출 수
  있습니다(타각 자체는 계속 됩니다 — 위치 확인만 빠집니다).
- **철회**: 동의를 완전히 철회하면 기존에 쌓인 내 위치정보가 **지체 없이**
  삭제 처리됩니다(다음 정기 파기 배치를 기다리지 않습니다).
- **정정**: 위치 좌표 자체(GPS 관측값)는 개인이 직접 고치는 항목이 아닙니다.
  위치 판정 결과(예: "사업장을 벗어나 등록됨" 표시)에 이의가 있으면 일반
  정정신청으로 접수해 주세요 — 관리자가 확인합니다.

## 연차·보상휴가 신청

앱/웹에서 신청 → 결재선을 따라 자동으로 담당 관리자에게 전달됩니다. 담당자가
휴가 중이면 대결/위임 설정된 사람에게 자동으로 넘어갑니다. 처리 결과는
알림으로 옵니다.

## 정정 신청은 언제 하나요?

타각을 깜빡했거나, 시간이 잘못 찍혔거나, 휴게를 못 받았을 때 앱/웹에서 정정을
신청하세요. 관리자 승인이 나면 반영됩니다. **원본 기록 자체는 지워지지
않고, 보정 내용이 별도로 추가되는 방식**이라 어떤 정정이 있었는지 항상 이력이
남습니다.

## 문제가 생기면

- 앱/키오스크가 아예 안 열릴 때 → 사업장 관리자에게 알리고, 시간을 메모해
  두었다가 복구 후 수기로 보고해 주세요.
- 급여명세서 시간이 이상해 보일 때 → 관리자에게 정정 신청 먼저 시도해
  주세요. 마감 이후에는 재마감 절차가 필요해 시간이 더 걸릴 수 있습니다.
